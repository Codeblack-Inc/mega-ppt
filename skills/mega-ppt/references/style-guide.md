# 디자인 시스템 — 보고서체

16:9 (13.333 × 7.5 in), 흰 배경. 한국 사업계획서·과제 발표자료에서 쓰는 **보이는 격자** 방식이다. 모든 요소는 테두리가 있는 칸 안에 들어가고, 옆 칸과 글자 크기·머리 높이·아랫선을 맞춘다. 그림자·그라데이션·3D·반투명 막은 쓰지 않는다. 모서리는 직각이다(휴대폰·태블릿 몸체만 예외). 기본 색은 [mega BI](https://github.com/Codeblack-Inc/mega-bi)의 잉크·페이퍼·coral 계열을 따른다.

## 토큰 (`build_deck.py`의 `THEME`)

| 토큰 | 기본값 | 용도 |
|---|---|---|
| `font` | Pretendard | 전체 서체 (라틴+한글) |
| `ink` | `#17152B` | 헤드라인, 탭, 번호 칸, 굵은 선 |
| `text` | `#2B293B` | 본문 |
| `muted` | `#68657B` | 출처, 캡션, 보조 설명 |
| `rule` | `#DED9ED` | 옅은 구분선 |
| `soft` | `#F6F5FA` | 요약 상자, 항목 열, 캡션 띠 |
| `paper` | `#FFFFFF` | 배경 |
| `accent` | `#B5452D` | 공식 coral `#F37055`에서 파생한 대비용 강조색. **헤드라인 강조 + 한두 곳** |
| `title_style` | `tab` | 패널 제목: `tab`(잉크 탭 + 1.5pt 선) · `bar`(잉크 띠) · `line`(굵은 제목 + 선) |

**파생 토큰**은 위 값에서 자동으로 계산된다. 덱에서 `accent`나 `ink`만 바꿔도 나머지가 따라온다(직접 덮어써도 된다).

| 토큰 | 계산 | 용도 |
|---|---|---|
| `ink2` | ink 18% 밝게 | 쉐브론, 막대, 화살표, 보조 노드 |
| `grey1` · `grey2` | ink→rule 60% · 82% | 차트 2·3번 계열, 보조 막대 |
| `line` | rule→ink 22% | 칸 테두리 0.75pt (rule은 프로젝터에서 안 보인다) |
| `head` | soft·rule 중간 | 표 머리, 카드·KPI 머리 띠 |
| `accent_soft` | accent 90% 밝게 | 강조한 행·칸의 바탕 (강조할 때만) |
| `on_dark` · `on_dark_rule` · `accent_on_dark` | ink·accent 밝게 | 잉크 바탕 위 보조 글자·선·강조 |

deck.json의 `theme`으로 일부만 덮어쓴다:
```json
"theme": { "accent": "#E4572E", "font": "Noto Sans KR" }
```
브랜드 색을 받으면 `accent`만 바꾸는 것을 우선한다. `accent`는 흰 글자와 함께 쓰는 색면에도 쓰이므로 대비를 확인한다.

## 선 굵기
| 이름 | 굵기 | 쓰는 곳 |
|---|---|---|
| STRONG | 2.0pt | 헤더 아래 선, 목차 선 |
| FRAME | 1.5pt 잉크 | 칸 윗변, 패널 탭 아래 선, 표 위·아래 |
| BORDER | 0.75pt `line` | 칸 테두리 |
| HAIR | 0.5pt | 표 안쪽 선, 행 구분 |

## 타입 스케일 (pt)
| 요소 | 크기 |
|---|---|
| 헤드라인 | 20 bold (최소 17, 최대 2줄) |
| 핵심 요약 상자 | 11.5 (최소 10) |
| 패널 탭 제목 | 10.5 bold 흰 글자 |
| 본문 불릿 | 11 → 칸을 채울 때까지 13(폭 4in 이상) 또는 12까지 커짐, 최소 9 |
| 카드·사분면·단계 본문 | 11 → 12.5, **옆 칸과 같은 크기** |
| 표 | 10.5 → 12, 최소 8 |
| 캡션 · 출처 | 9.5 · 8.5 |

글자 크기를 직접 지정하지 않는다. 엔진이 칸에 맞춰 **키우거나 줄이고**, 옆 칸들은 한 크기로 맞춘다. 남는 높이는 문단 간격으로 나눈다. 그래도 칸이 절반 넘게 비면 경고가 나오니 내용을 보강한다.

## 불릿 위계
| 표기 | 모양 | 용도 |
|---|---|---|
| `"**제목**"` (항목 전체가 굵게) | □ 굵은 잉크 | 소제목 |
| `"항목"` | ○ | 본 항목 |
| `"- 항목"` | - (1pt 작게) | 하위 항목 |
| `"※ 항목"` | 회색 주석 | 단서·기준 |

## 강조 예산
강조색은 **헤드라인의 `**강조**` + 데이터 한두 곳**에만 쓴다. 제목 탭, 목차, 번호, 불릿, 역할명에는 쓰지 않는다. 한 장에서 헤드라인 강조, `highlight`를 준 패널, `**`가 든 callout이 합쳐 4곳 이상이면 경고가 나온다.

## 쓰지 않는 것 (AI가 만든 티가 나는 장치)
- 동그라미 번호 배지, 이니셜 원형 아바타, 파스텔 원 안의 아이콘, 가운데 정렬 아이콘 카드 격자
- 둥근 막대·칩·노드, 왼쪽 강조 띠가 있는 분홍 콜아웃, 윗줄만 색칠한 KPI 타일
- 점선 고리를 두른 플라이휠, 빛나는 네트워크 이미지, 사진 위 반투명 막
- 맥 신호등 점, 알약 URL 바, 사다리꼴 노트북 받침, 흰 공간에 떠 있는 기기 목업
- 한국어 덱 속 영어 소제목(CONTENTS, VISION, WHY NOW), 한영 중복 제목
- 칸의 40% 이상을 비워 두는 작은 글자, 옆 칸끼리 다른 글자 크기, 글자 한 줄만 있는 전면 어두운 장표
- `< 캡션 >` 형식 — 캡션은 `[그림 n]` 띠로 단다
