# 콘텐츠 밀도 기준

실제 한국 사업계획서·과제 발표자료·공공기관 보고서 5종(206장)을 분석한 결과다. 이 스킬의 기본 독자층이다.

| 유형 | 장당 글자 수(중앙값) | 도형 수 | 구성 |
|---|---|---|---|
| 공공기관 보고서 | ~830자 | ~70개 | 패널 3~6개 + 표 + 미니차트 + 간트 |
| 사업계획서 | ~450자 | ~20개 | 헤드라인 2줄 + 다단 패널 + 표/차트/구조도 |
| 과제 검토·발표 | ~240자 | ~13개 | 표 + 차트 + 이미지 + 불릿 |
| 시연·성과 공유 | ~90자 | ~7개 | 스크린샷 중심 |

## 기본값: 사업계획서 수준 (장당 300~600자)
- 본문 슬라이드는 **패널 2~4개**. 패널 하나만 있으면 내용이 부족하거나 레이아웃을 잘못 고른 것이다.
- 헤드라인(결론 문장) + 리드 한 줄 + 패널. 리드는 헤드라인을 반복하지 말고 근거 수치나 맥락을 보탠다.
- 불릿은 명사형 종결("~ 확보", "~ 필요", "~ 구축")로 짧게 쓴다. 한 항목은 1~2줄.
- 숫자에는 단위와 기준 연도를 붙인다. 데이터 슬라이드에는 `source`를 단다.

## 밀도 조절
- 사용자가 "발표용", "임원 보고", "간결하게"라고 하면 장당 150~250자로 줄이고 패널은 1~2개, `kpi`·`callout`을 늘린다.
- "제출용", "심사용", "상세하게"라고 하면 장당 600~900자로 늘리고, 패널 4~6개, 표와 2단계 불릿을 쓴다.

## 채움 규칙
엔진은 글자를 칸에 맞춰 키우고(본문 최대 13pt), 옆 칸끼리 같은 크기로 맞추고, 남는 높이는 문단 간격으로 나눈다. 그래도 비면 **내용이 부족한 것**이다. 글자 크기나 칸 높이로 가리지 말고 근거를 보탠다.
- 카드·사분면·단계 하나에 ○ 항목 3~4개, 그중 하나 이상은 숫자를 담는다. 짧으면 `- ` 하위 항목, `※` 기준, 카드 `value`·`note`를 더한다.
- 표는 칸을 채울 만큼 행이나 열을 두거나, 표 아래에 callout을 둔다.
- KPI에는 기준을 밝히는 `sub`(예: "전년 대비 +3%p")를 단다.
- 전면 슬라이드(표지·목차·구분·강조·마무리)도 과제 정보, 섹션 설명, 근거 수치로 채운다.

## 빌드 경고 대응
- `overflows` → 문장을 줄이거나 패널의 `w`/`h`를 키운다. 글자 크기를 직접 줄이지 않는다.
- `fills only N%` → 칸이 절반 넘게 비었다. 내용을 보강하거나(근거, 수치, 하위 불릿) 행 `h`를 줄인다.
- `accent highlights` → 강조가 4곳 이상이다. 헤드라인 강조 외에 한두 곳만 남긴다.
- `focus … widened` → `focus` 영역이 칸 모양과 너무 달라 주변이 많이 딸려 들어왔다. 칸 비율에 가까운 영역을 고른다.
