AI가 스토리라인을 짜고, 패널을 조합해 편집 가능한 PowerPoint 장표를 만듭니다.

한국식 사업계획서·과제 발표 수준의 밀도를 기본값으로 합니다. 슬라이드 하나는 결론 문장 헤드라인과 그 결론을 증명하는 패널 2~4개로 구성됩니다. 아래 예시는 모두 deck.json으로 생성했고, 장표마다 원본 JSON을 볼 수 있습니다.

HOW IT WORKS

      
    
        
  1. 브리핑
    청중, 목적, 분량을 확인하고 첨부 문서와 데이터를 읽습니다. 수치는 소스에서만 가져옵니다.
    2. 
        
  2. 스토리라인
    헤드라인만 먼저 나열해 보여 드립니다. 헤드라인만 이어 읽어도 논리가 서야 합니다.
    3. 
        
  3. 패널 설계
    슬라이드마다 헤드라인을 증명할 패널(표·차트·SWOT·아키텍처·로드맵·이미지 프레임 등 32종)을 격자로 조합합니다.
    4. 
        
  4. 빌드와 검수
    python-pptx로 네이티브 표와 차트를 생성하고, 글자 넘침과 빈 공간을 경고로 잡습니다. 이어 렌더링 이미지를 AI가 직접 보고 고칩니다.
    5. 
      

    

    

      
INSTALL

      
Claude Code

      
/plugin marketplace add Codeblack-Inc/mega-ppt
/plugin install mega-ppt@mega-ppt

      
Codex

      
codex plugin marketplace add Codeblack-Inc/mega-ppt
codex plugin add mega-ppt@mega-ppt

      
필요 도구: uv, 시각 검수용 LibreOffice, 권장 폰트 Pretendard. 설치 후 "이 보고서로 발표자료 10장 만들어줘"처럼 요청하면 됩니다.
